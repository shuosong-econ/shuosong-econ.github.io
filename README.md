# Shuo Song — An Open Archive

个人学术网站的静态重构。视觉围绕一套“封存的光学档案”展开：同一组刻纹介质贯穿接入、解封、目录和阅读；隐藏的摄影空间则让光重新成为色彩。

## 本地预览

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173>。网站无需构建、API key、服务器应用或运行时库，适合直接部署到 GitHub Pages。进入后会请求一次 IP 大致地点；该请求失败时网站仍完整可用。

维护命令：

```sh
npm ci
npm run check
npm run format
```

## 访问体验

每次刷新，包括已有栏目锚点的 URL，都重新开始访客接入。入口是一片不透露档案内容的留白与微光，约 4.8 秒内依次显示建立信号、开放通道、等待身份三段提示；**Skip wait** 可跳过等待。只有通道准备完成且名字去除首尾空格后非空，**Enter** 才亮起，删除名字会再次关闭它。**Continue anonymously** 是独立入口，不要求填写名字。确认后系统先回应访客，再授予通行并展开场景。名字仅在本次页面生命周期的内存中使用，以纯文本显示，不写入存储、URL 或发送给服务器。这是公开网站的视觉入口，不是真实身份认证。

确认后，一摞档案从上方加速落入，逐渐减速悬停，并在余下的沉降中开始沿弧线展开。轨迹使用端点速度、加速度为零的五次曲线，逐帧采样后由浏览器线性插值；展开叠加抬升、深度与轻微侧倾。下落与展开重叠，不再硬停后重启；低动态模式直接呈现。访客首先看到栏目选择，而非个人介绍。每片的刻纹由 Canvas 独立绘制，没有外部模型、PV 素材或自动播放音频。悬停时点击区域保持不动，只移动内部视觉层；选择档案后，整个背景先淡出，选中的那片再移动到中央并进入阅读层。

- **Intro**：个人介绍、教育经历、研究兴趣和联系地址。
- **Research**：原站的两项进行中研究。项目记录明确说明稿件与摘要尚未公开，没有虚构论文内容。
- **Journal**：为未来文章保留的笔记空间，目前没有公开文章。
- **Library**：《稼轩词编年笺注》。
- **Elsewhere**：通过目录边缘的漏光进入，收录原站全部 16 项摄影作品。柔和的光晕与光束将当前画面过曝，进入摄影空间；返回时光线逐渐消退。背景从照片采样六种色彩，持续缓慢流动，换片时平滑迁移。支持接触印相筛选、大图、键盘翻页和触屏滑动，已移除 View original 入口。

Index 支持 Cmd/Ctrl + K。照片只有在本次访问发现 Elsewhere 后才加入搜索结果。栏目内的返回和浏览器前进/后退不会重播开场；刷新和“Begin again”会重播。

桌面并列展开四片档案；手机显示一片，并通过明确的四项选择器切换。触摸、键盘、鼠标均可使用，隐藏入口也能通过键盘焦点发现。系统减少动态效果和手动暂停会关闭动态绘制与转场等待，同时保留主动进入的步骤。无 JavaScript 时可直接阅读正文并打开原图链接。

浏览器只保存动效偏好，不保存“已访问”或准入状态。没有统计脚本或外部字体 CDN。

目录中的访客通行卡显示本次名字、临时通行编号、本机时间和大致访问地点。访客选择 Enter 或匿名进入后，浏览器自动请求一次 `https://api.ipapi.is/`，不携带名字、cookies 或 referrer，不调用 GPS。只使用返回的城市（缺失时地区）与国家，不保存 IP、坐标或响应内容；换栏目不重复查询。“Begin again”会终止旧请求并开始新的访问。服务超时（5 秒）、限流、离线或没有有效地点时显示 **Somewhere on Earth**，不会阻塞入场，也不会重试。

[接口官方文档](https://ipapi.is/developers.html)说明支持浏览器跨域调用，匿名接口无需 key，目前每个客户端公网 IP 每 UTC 日最多 100 次查询；共享网络可能共用配额。此功能依赖第三方服务的可用性，IP 地点也可能反映 VPN 或网关。通行卡的 **About this connection** 提供简短说明。

## 文件与维护

- `index.html`：静态内容、各个场景、导航和原生对话框。
- `styles.css`：设计变量、介质造型、解封状态、响应式布局与动效。
- `script.js`：接入时序、导航转场、图像预解码、搜索和原创刻纹绘制。
- `assets/photos/`：800px 缩略图及 1920px 大图 WebP 副本。原件完整保留在 `figures/`。
- `scripts/optimize_images.py`：重新生成图片副本，依赖 Python Pillow。
- `scripts/check.mjs`：验证 HTML ID、锚点、资源路径、16 套照片和静态部署文件。
- `.verification/`：本地验收截图和旧版备份，已被 Git 忽略。

入口状态在 `showEntry` / `enterArchive` 中管理；界面根据 `data-phase` 从 sealed → falling → landed → unfolding → ready 连贯展开；`revealArchive` / `unfoldArchive` 用 Web Animations 控制重叠的轨迹，CSS 管理最终布局。导航由单个异步转场独占，过程中锁定交互，避免快速点击生成相互竞争的页面。照片使用预解码和请求序号，连续翻页只提交最新请求。`crossLight` 管理光线吞没与消退，`updateAtmosphere` / `drawAtmosphere` 管理照片取色及流动背景。

更新研究时同步修改 HTML 条目和 `papers` 列表。添加照片时更新 `photos` 列表、无 JavaScript 的原图链接及界面总数，再生成 WebP。不要移除 `figures/` 原件或 Google Search Console 验证文件。

档案刻纹最高约 24 fps，手机只更新当前介质；离屏、后台和阅读页会停止绘制。相册背景使用较小的 Canvas，在桌面约 18 fps、手机约 12 fps 绘制，仅相册可见且页面在前台时运行。暂停/减少动效时静态呈现，并跳过坠落与光线转场。动画偏好保存在 `ss-archive:motion`。

## 上线

改版开发分支为 `codex/research-observatory`，通过 PR 审阅改动。推送开发分支不会将改动合并到 `main`；正式上线时，将 PR 合并到实际的 Pages 发布分支，并确认部署成功。`.nojekyll` 已包含，网站不需要新的构建工作流。

GitHub 写入通过本机 Git 凭据或 GitHub CLI 的浏览器登录授权；不要把密码或 token 放进项目或聊天。登录方法参见 [GitHub CLI 官方说明](https://cli.github.com/manual/gh_auth_login)。

## 验证

`npm run check` 检查脚本语法及静态资源完整性。真实浏览器检查覆盖每次刷新重新接入、目录与阅读切换、手机选择器、索引、研究弹窗、隐藏空间、照片筛选及大图、连续翻页和暂停动效。桌面、平板、窄屏手机与横屏手机均独立检查；这些浏览器尺寸检查不等同于所有实体设备的验收。
